## G9: plan comparison (report only)

What FlockStack's Free plan allows today, from `lib/plans.js` `FREE_PLAN` and the README's Free plan section: the REST API and MCP (every key level, connected apps, the approval queue), 1 newsletter, 2,500 subscribers, 10,000 emails a month, 2 automations besides the welcome email, 1 webhook endpoint, 5 AI requests a day, shared sending IPs only, and the "Sent with FlockStack" link.

| Competitor's documented offer | FlockStack today | Cost of matching | Recommendation |

| Kit: API on every plan, Free up to 10,000 subscribers | API and MCP on Free already; 2,500 subscribers | Subscribers cost little to store. Sending is what costs, and the 10,000 emails a month cap bounds it whatever the list size. The real cost is abuse: a bigger free list draws more spam sign-ups, which the Free guards (`FREE_GUARDS`) were sized for at 2,500. | Leave API and MCP as they are, since that parity already holds. ## Behavior changes that could affect existing customers

1. New accounts only: a full access key or app on a new account's newsletter gets `202 approval_required` for sends, deletes and billing changes where it used to act at once. Existing accounts are unchanged until the owner turns the switch on.
2. On any account, a team member's dashboard changes now appear in the agent activity log.
3. The approval decision's log line now ends with who decided and how.
4. Every API and MCP answer has four new `RateLimit-*` headers.
5. A connected app re-consenting on an account with several newsletters sees a new "Newsletters it reaches" field (default: all, as before).

## Rollout order I recommend

1. Release G7, G8, G3, G4, G5 and G6 together: additive, opt-in, no change for existing keys or apps.
2. Release G1's default for new accounts and the Approvals page banner. Watch `approval_required` rates and support questions for a week.
3. Turn on G2 (approvers, step-up) for your own account first, check the code email arrives through SES, then announce it.
4. After a notice email, decide whether to switch older accounts' newsletters to the default; the banner already offers it.
